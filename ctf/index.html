Play the CTF

A capture-the-flag training game you run on your own machine. Each challenge is a small, deliberately vulnerable web app with synthetic data. Find the flag hidden in it, submit it here, and the sensor in front of the app records which techniques you used to get there.

The vulnerable app runs in Docker on an internal-only network with no route anywhere, and only listens on 127.0.0.1. This page talks to it from your browser; nothing on your machine is reachable from outside.

Practice mode. The leaderboard isn't live yet, so flags are checked by your local stack and nothing is sent anywhere. Everything else works the same.

1Start the game on your machine

You need Docker (Docker Desktop on Mac or Windows). Then, in a terminal:

curl -fsSL https://aaronjadler.github.io/ctf/docker-compose.yml -o cyberguard-ctf.yml
docker compose -f cyberguard-ctf.yml up
Download the compose file

Stop it with Ctrl+C, and remove everything with docker compose -f cyberguard-ctf.yml down -v.

2Connect this page to it

Your browser may ask to let this site connect to apps on your device. Allow it: that's how this page reaches the game running on 127.0.0.1.

How it works

TargetThe vulnerable app. Internal network only, read-only, synthetic data.
SensorDetection rules tag each request with the technique it used (IDOR, SQLi, XSS…).
AgentBridges this page and the target on 127.0.0.1, and batches telemetry.
Cloud APIReceive-only. Issues your per-player flag and ranks validated solves.
