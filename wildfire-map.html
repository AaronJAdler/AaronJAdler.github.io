California wildfire risk, live on ArcGIS

Every 3 hours an open-source pipeline scores the state on a hexagon grid from NASA satellite detections, CAL FIRE and NIFC interagency incidents and perimeters, and National Weather Service fire weather alerts. This ArcGIS Online app reads the pipeline's published files directly and lays them over CAL FIRE's Fire Hazard Severity Zones, so it always shows the latest run.

How a run works

  1. ScheduleGitHub Actions starts a run at 17 minutes past every third hour.
  2. FetchCAL FIRE, NIFC WFIGS, NASA FIRMS and NWS, with an HTTP cache and retries.
  3. ValidateBad records are quarantined, and a source that fails is marked stale or down rather than read as "no fires".
  4. ScoreEach H3 hexagon gets 0–100 from satellite heat, incidents and fire weather. Alert state is kept in DuckDB between runs.
  5. PublishGeoJSON and status files are deployed to GitHub Pages. ArcGIS Online reads them directly.

What the map shows

Risk hexagons0–100 per 36 km² cell: satellite heat, nearby incidents, and fire weather.
Active incidentsCAL FIRE and NIFC WFIGS, merged so each fire appears once.
Fire perimetersMapped outlines from WFIGS, used to attribute heat to fires.
Fire Hazard Severity ZonesCAL FIRE's official long-term hazard map (moderate to very high).
Fire Responsibility AreasWhich agency is responsible: state, federal or local.
